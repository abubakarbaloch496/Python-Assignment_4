# Python-Assignment_4
Python Assignments: Conditionals and For Loops 
Assignment 1: Number Analysis Program Instructions:
1. Use a for loop to print numbers from 1 to 10.
2.  For each number:    - If number is even → print 'Even'    - If number is odd → print 'Odd'
3. Also:    - If number is divisible by 3 → print 'Divisible by 3' 
Expected Output Example: 1 → Odd 2 → Even 3 → Odd, Divisible by 3 
Concepts Covered: - for loop - if-else - multiple conditions 
Bonus Task: Count how many even numbers are there from 1 to 10. 
Assignment 2: Student Marks Analyzer Instructions:
 1. Use a for loop to input marks of 5 students.
 2. For each student:    - If marks >= 80 → Grade A
     - If marks >= 60 → Grade B
        - If marks >= 50 → Grade C    - Else → Fail
  3. At the end:    - Print total number of students who passed    - Print total number of students who failed 
Example Output:
Student 1: B
Student 2: A
Student 3: Fail 
Concepts Covered: - for loop with input - if-elif-else - counters 
Bonus Task: Find and print the highest marks among all students.
